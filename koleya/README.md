# Koleya — «Пять футов»

Историческая железнодорожная стратегия о строительстве дорог Российской империи и СССР.
Telegram Mini App внутри бота «Билли», запуск командой `/koleya`. Бесплатный образовательно-познавательный проект, одиночная кампания: игрок принимает решения,
которые принимали реальные инженеры, а в конце главы видит, как было на самом деле.

Название — по ширине колеи 5 футов (1524 мм), выбранной для дороги Петербург–Москва.

## MVP
- Пролог: Царскосельская дорога (1836–1838), обучение.
- Глава 1: Петербург–Москва (1842–1851).

## Документы
- `CLAUDE.md` — правила для Claude Code (читать первым).
- `docs/GDD.md` — геймдизайн MVP.
- `docs/ARCHITECTURE.md` — техническая архитектура.
- `docs/DESIGN.md` — визуальный язык.
- `docs/FACTS_POLICY.md` — правила исторической достоверности.
- `docs/ROADMAP.md` — этапы разработки с критериями приёмки.
- `data/` — факты, карты, события, советники, баланс, викторина.

## Где что лежит
Игра встроена в репозиторий «Билли» каталогом `koleya/`. Слои, команды и отступления от исходной архитектуры — в `docs/BILLY_INTEGRATION.md`.
