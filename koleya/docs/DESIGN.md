# Визуальный язык

## Принцип: у каждой эпохи свой стиль
Интерфейс меняет «материал» вместе с главой: игрок буквально листает историю техники графики.
Движок и раскладка общие, меняются только тема (токены), шрифты, SVG-узоры карты и стиль иллюстраций.

| Эпоха | Главы | Материал |
|---|---|---|
| Гравюра и старинный чертёж | пролог, глава 1, концессии | бумага ручного отлива, железо-галловые чернила, штриховка, красная тушь трассы |
| Литография и открытка | Транссиб | тоновая литография, подкраска, виньетки |
| Советский плакат и схема | индустриализация, война | плоский цвет, конструктивистские шрифты, схемы Госплана |
| Технический буклет | БАМ, скорость | офсет, модульная сетка, фотографика |

Темы переключаются атрибутом `data-era` на корневом элементе. Всё, что зависит от эпохи, берётся
из токенов темы, а не зашивается в компоненты.

## Эпоха 1: «Гравюра и старинный чертёж» (MVP)

Идея: инженерный лист 1840-х. Карта — чертёж трассы с штриховкой рельефа, как на гравированных
картах губерний. Депеши — казённая бумага. Иллюстрации — гравюра на меди и литография.
Единственный яркий элемент — красная линия трассы, как у изыскателей.

### Палитра
| Токен | Цвет | Роль |
|---|---|---|
| `--paper` | `#E8E0CB` | фон, бумага |
| `--paper-deep` | `#DCD1B6` | депеши, панели |
| `--ink` | `#2A2119` | текст, контуры, штриховка |
| `--ink-faded` | `#6E5E4B` | вторичный текст, сетка, плановые участки |
| `--route` | `#9C1C1C` | трасса, главный акцент |
| `--wash-water` | `#6D8CA3` | реки, лёгкая акварельная подкраска |
| `--wash-marsh` | `#7D8A5C` | болота и лес, подкраска штриховки |

### Шрифты
- **Old Standard TT** — заголовки, депеши, карточки фактов. Выросла из книжного набора
  рубежа XIX–XX веков, кириллица родная, курсив подходит для «рукописных» пометок.
- **PT Sans** — интерфейс, цифры ресурсов, кнопки. Читается на мелком мобильном кегле.

### Карта
- Рельеф — SVG-паттерны штриховки: лес — короткие штрихи, болото — горизонтальные пунктиры,
  холмы — «гусеницы» (бергштрихи), реки — двойная линия с подкраской.
- Готовый участок — сплошная красная линия со шпалами-штрихами, в стройке — пунктир,
  план — тонкая линия `--ink-faded`.
- Станции — кружки, столицы — двойные кружки, подписи курсивом Old Standard.
- Рамка карты — тонкая двойная линия, картуш с названием главы в углу.

### Раскладка (мобильная)
```
┌────────────────────────────┐
│ Лето 1845   Казна 12 400   │  строка ресурсов
│ Благоволение ▮▮▮▮▯  Артели 38│
├────────────────────────────┤
│  ╔═ картуш ═╗               │
│   КАРТА-ЧЕРТЁЖ (SVG)        │  ~60% высоты
│   Петербург ━━━━╍╍╍╍ Москва │
├────────────────────────────┤
│ Участок: Тосно — Любань     │  нижняя панель
│ Работы 62%, 6 артелей [+][−]│
└────────────────────────────┘
      [ Завершить сезон ]         MainButton Telegram
```
События — модальная «депеша» на `--paper-deep`, заголовок Old Standard, варианты кнопками,
реплики советников курсивом под вариантами.

### Иллюстрации
Общественное достояние (гравюры и литографии 1830–1850-х, например литографии Беггрова)
или генерация в едином стиле. Шаблон промпта для генерации:
«гравюра на меди 1840-х годов, тонкая штриховка, монохром сепия, лёгкая акварельная подкраска,
без современных деталей, [сюжет]».

### Движение
Одна постановочная анимация: достроенный участок «дочерчивается» красной тушью вдоль трассы.
Остальное — мгновенные состояния. `prefers-reduced-motion` — без анимации.

### Правила
- Текст по левому краю, строки до ~70 знаков.
- Разделители — тонкие линии туши, без карточек с тенями.
- Цифры ресурсов — табличные (tabular-nums).
- Контраст текста не ниже AA, фокус клавиатуры виден.
- Светлая тема — основная. Тёмная для этой эпохи — «ночная калька»: инверсия бумаги и туши, позже.
